## 🚀 Deployment

**Currently deployed on Vercel** → [in-alpha-nine.vercel.app](https://in-alpha-nine.vercel.app)

Connected to this GitHub repo (`main` branch). Every push auto-deploys in ~20 seconds.

### Deploy your own copy

**Option 1 — Netlify Drop (no account needed)**
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag `index.html` onto the page
3. Live instantly

**Option 2 — Vercel (connected to GitHub)**
1. Fork this repo
2. Go to [vercel.com](https://vercel.com) → Import Project
3. Select the repo → Deploy
4. Auto-deploys on every push ✅

**Option 3 — GitHub Pages**
1. Go to repo **Settings → Pages**
2. Source: `main` branch, `/(root)`
3. Save → live at `username.github.io/portfolio`

## ✏️ How to Update

Everything lives in `index.html`. Open it in VS Code or edit directly on GitHub.

| Want to change | Search for |
|---|---|
| Name / title | `Pavitr Kumar Swain` |
| Availability status | `Open to Data & AI Roles` |
| New project | Copy a `<div class="pcard">` block |
| New job | Copy a `<div class="exp">` block |
| New cert | Copy a `<div class="crow">` block |
| Accent color (gold) | `#c9b99a` |
| Background color | `#0a0a0a` |
| Hero stats numbers | `hstat-n` class values |
