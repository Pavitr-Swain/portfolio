# Pavitr Kumar Swain — Portfolio

A dark, editorial-style personal portfolio built with pure HTML, CSS, and vanilla JavaScript. Zero dependencies, zero frameworks, zero build steps.

---

## 🚀 Deploy in 60 Seconds (Recommended — Netlify Drop)

This is the fastest way. No account needed.

1. Go to **[netlify.com/drop](https://app.netlify.com/drop)**
2. Drag and drop the `pavitr-portfolio.html` file onto the page
3. Done — you'll get a live URL like `random-name.netlify.app` instantly

To get a custom URL like `pavitrswain.netlify.app`:
- Sign up for a free Netlify account
- Go to **Site Settings → Change site name**
- Type your preferred name and save

## 🐙 Deploy via GitHub Pages (Permanent + Free Custom Domain)

This gives you a URL like `pavitr-swain.github.io/portfolio`

### Step 1 — Rename the file
Rename `pavitr-portfolio.html` → `index.html`

### Step 2 — Create a GitHub repo
1. Go to [github.com](https://github.com) and sign in
2. Click **New Repository**
3. Name it `portfolio` (or anything you like)
4. Set it to **Public**
5. Click **Create Repository**

### Step 3 — Upload the file
1. Click **Add file → Upload files**
2. Drag in your `index.html`
3. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Go to **Settings → Pages**
2. Under **Source**, select `main` branch and `/ (root)` folder
3. Click **Save**
4. Wait 1–2 minutes — your site will be live at:
   `https://your-github-username.github.io/portfolio`

## ▲ Deploy via Vercel (Fastest with GitHub)

1. Push your file to a GitHub repo (see above)
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub
3. Click **Add New Project**
4. Select your portfolio repo
5. Click **Deploy** — no settings to change
6. Live URL given instantly. Auto-deploys on every push.

## 🌐 Custom Domain (Optional)

Once deployed on Netlify or Vercel, you can connect a custom domain like `pavitrswain.com`.

**Buy a domain cheaply:**
- [Namecheap.com](https://namecheap.com) — `.com` domains from ~₹800/year
- [Hostinger.in](https://hostinger.in) — often has ₹99 first-year deals

**Connect it:**
- In Netlify: **Site Settings → Domain Management → Add custom domain**
- In Vercel: **Project Settings → Domains → Add**
- Follow the DNS instructions they give you (takes ~10 mins to go live)

## ✏️ How to Update Your Portfolio

The entire site is one file — `pavitr-portfolio.html`. Open it in any text editor (VS Code recommended).

| What to update | Search for this in the file |
|---|---|
| Your name / title | `Pavitr Kumar Swain` |
| Job status / availability | `Open to Data & AI Roles` |
| Add a new project | Copy a `<div class="pcard">` block |
| Add a new cert | Copy a `<div class="crow">` block |
| Add a new job | Copy a `<div class="exp">` block |
| Change accent color | `#c9b99a` (warm gold tone) |
| Change background | `#0a0a0a` |

After editing, just re-upload the file to Netlify Drop or push to GitHub — site updates immediately.
